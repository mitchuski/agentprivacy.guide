🛠️ The Workbench Skills

Fifteen working skills from the local workbench (~/.claude/skills) that the federation and the arena lanes run on — not yet promoted into the canonical agentprivacy-skills-v5 tree. A skill that runs is work; these run daily.

🗂️ The FedWiki Toolbox

the tooling the federation itself runs on — peers of the published wiki-sync and wiki-watch skills.

  • Fedwiki Cohere Sync — Sync per-session answer pages from a source-of-truth FedWiki out to milestone subdomains with a coherence check, and broker owner cookies so agents get delegated, host-scoped write permission without ever seeing the raw credential.
  • Fedwiki Transcribe — Transcribe video/audio assets hosted on a FedWiki (Smallest Federated Wiki) page using local whisper.
  • Wiki To Pdf — Pull FedWiki timeline pages and render formal executive-brief PDFs - one brief per timeline plus a combined dossier whose .
  • Tile From Page — Read a FedWiki page's content, semantically choose a glyph + color + category for it, and write a tileglyph navigation tile (the wiki-plugin-tileglyph item type) into a destination page — matching a Root Tiles registry for federation-wide consistency, or minting a new canonical entry.

⚛️ The Quantum Workbench

the ecdsa.fail arena lane — reversible-circuit optimization, validation, island hunting, and benchmark forensics.

  • Ecdsafail Circuit Optimization — Use this skill whenever designing, reviewing, or modifying ECDSA Fail / quantum ECC point-addition circuits to reduce qubit count, Toffoli count, or score.
