The Field Guide — Privacy

The trust-graph work behind the Hitchhikers Field Guide — a walking AR client that needed real one-hop trust, met by the ToIP DTG trust-graph work, which had it and had never been near a street. Built 2026-08-13 → 16 on the field farm (privacy.fieldguide), served to the team from the embassy Pis, and merged here 2026-08-17 as the federation's thirteenth site.

What this is

A counter-spec built as evidence rather than argued as prose: eight suites, 124 properties, every ruling anchored to a test that fails if the ruling is broken.

Start at Field Guide Trust Overlay — it indexes everything else.

Run it yourself

The assets lane carries the workbench — the model, both sides' documents, the conformance vectors, and a captured run report. The Working Files indexes it. Node and Python standard libraries only; nothing to install, nothing to log into.
