The Star is a root representation of the model

Core observer principle, recorded from the First Person’s direction on 7 September 2026. This records intended architecture; it is not a new canonical mathematical claim or evidence of completed implementation.

“As the star is a root thing it will fill information and data over time actually once we have the agents this is how they are visualised geometrically its fitting the model visually across the work.”

The Star is a geometric representation of the agentprivacy model. Treating it only as shared artwork misses its role: as agents arrive and contribute, permitted knowledge, promises, artefacts, relationships and evidence can populate that representation over time. A common visual identity follows from a common model, rather than defining it.

The correction this observer must carry

Earlier recommendations emphasised a reusable visual component and site styling. The First Person corrected the emphasis: the shared foundation needs a data-to-geometry contract. Styling is one expression of that contract. Future work should start from source-defined model semantics and actual evidence, not retrofit meaning onto a decorative graph.

Invariants for implementation

  • Resolve coordinates, vertex meanings and transformations against their governing corpus records. Preserve unresolved source conflicts; do not invent canonical seats. The current six-bit MODEL space has 64 states, not 64-bit vertex identifiers. A display offset is not a new model position.
  • Map each rendered entity to stable identifiers, source/version, permitted context and time. Separate an agent instance, persona, knowledge item, promise, credential and evidence record. Similar geometry does not merge their meanings.
  • A graph view belongs to an observer and their permitted perspective. There is no implied complete global trust graph. Missing evidence is unknown, not proof of absence; overlap is not automatically trust.
  • Preserve distinctions among illustrative, proposed, observed, signed, verified, expired and revoked states. Define what verification establishes for each type; a signature, geometry or credential alone does not grant authority.
  • Make disclosure deliberate. VTA-held context is not automatically public scene data. Public site views, community views and personal views require different projections and service-enforced permissions.
  • A future ZKP establishes a specific supported statement about authenticated evidence. It does not compress the entire graph into a recoverable object or prove model conjectures merely by existing. Bind its scope and freshness to the actual protocol.
  • Time and change are part of the view: versioned snapshots, evidence updates, withdrawals and corrections must have explicit rendering behaviour. Apparent animation must never stand in for observed activity.

Across the ecosystem

Soulbis exposes the Star/key instrument; agentprivacy explains the model and its atlas; Labs connects the representation to applied research and cybersecurity; City exposes community activity and the participant’s permitted perspective; Spellweb connects source knowledge and lineage. These are proposed responsibilities to reconcile with current implementations. They should share model semantics while retaining their own purpose and permissions.

Next implementation gate

Pin the upstream geometry and model sources. Define the entity and edge schema, transforms, provenance, disclosure filters and temporal/status rules. Exercise an empty view, an illustrative fixture and a permitted real record. Demonstrate that switching observers cannot leak prior context, that revoked or expired evidence changes appropriately, and that a scene remains inspectable without WebGL. Only then describe the view as connected to real agent data.

The current Labs manifold remains an editorial rendering, and the City prototype does not yet supply this complete data contract. This principle directs their evolution without overstating their current capabilities.

Wider geometry and UOR

See geometry/UOR continuation: the Star, 64-state codex/torus and 42-station learning fold need explicit representation transforms. UOR registry research is part of the trust-foundation inquiry, with source-defined gaps and governance preserved.

City Key as a private agent perspective

The First Person extended this principle on 7 September 2026: begin with the existing Soulbis City Key, let an agent operating through a VTA maintain its private state and interpretation of relationships, and derive a scoped expression for each City encounter. Appearance, compressed meaning, observed work and verified predicates remain distinguishable. The agent's interpretation of permission is checked against service-side authority; it cannot authorize itself. A public projection must not contain the full private state, and repeated geometry or κ can itself disclose relationships.

Read the core observation and implementation proposal. The first milestone connects one existing key to one verified, scoped City permission decision; ZK follows an explicit DTG predicate, adversary and horizon. This is recorded architecture, not a claim that private-state projection or a production ZK permission protocol is already deployed.

Core artefact and temporal view

The First Person proposed a selectable core PFP/image or information artefact inside the Star on 8 September 2026. Its surrounding temporal ring should connect to the existing moving-ceiling model, once that model's actual source and semantics are pinned. Keep intrinsic SHAPE(key) separate from VIEW(key, modelVersion, observationTime, context): time changes the view, not key bytes or credential authority. Carry only an approved core projection into the extension and the City's compact floating orb. See design proposal. No decay mapping or new mathematical claim is adopted by this note.

Source reconciliation: the current Soulbis checkout retains ceilR, ceilTstar, applyCeiling and the heart/shell effects. The Soulbis implementation plan records their semantics and the extension transition, following the existing core proposal. See also the source-grounded observation. The exponential scenario models growing reconstruction reach; it does not establish literal information loss.
