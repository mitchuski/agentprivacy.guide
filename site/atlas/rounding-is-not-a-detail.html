💡 rounding is not a detail

concept · shared · knowledge

The public tier coarsens location to ~100m; JavaScript rounds midpoints up, Python and C# round to even — the same pin lands 110m apart, opposite sides of a street, and both implementations pass their own tests. A coarsening rule that does not name its rounding mode is not a rule. Generalises to every numeric field in a canonical encoding — found within an hour by a zero-shared-code consumer.

Two correct implementations, one pin, opposite sides of the street.
