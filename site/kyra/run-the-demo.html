Run the Demo

One command: pnpm host — the site, both apps, and the engine on one origin at localhost:1337.

Open /supervisor/ as the regulator and /agent/ as the agent (autonomous mode is on — it approaches and answers by itself). The dashboard's walkthrough sidebar ticks the ten demo beats off from engine state as you go.

Act I takes about three minutes; Act II about ninety seconds. The click-by-click script is docs/demo-runbook.md in the repository.
