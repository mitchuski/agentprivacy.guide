The Engine Room

One engine, many expressions. The frozen contracts (eight JSON Schemas, the probe registry, the engine interface) hash to a merkle root that three verification lanes re-derive; nothing downstream may drift.

The layers: packages/contracts (frozen truth) → services/verify (the harness: Σ, det, lattice, verdicts; assessment, understanding, issuance, ledger, pooling) → the demo-loop API → the two apps. Guardrails and zero-dep runtimes watch everything.

Identity and chain-registry providers are late-bound adapter lanes — the core never imports an ecosystem. Builders start at the repository's README.md and docs/architecture.md; the session-by-session record is in docs/chronicles/. See also The Chronicles.
