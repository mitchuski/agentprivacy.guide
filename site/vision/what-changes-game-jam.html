What changes

Stated changes. The clearest stated shift is reach: "we just have penetration into a new ecosystem we haven't really had an appearance with yet." Output changes too: "we've got a new game, like a new Hitchhiker, well, potentially several new Hitchhiker games," "putting them up on the plat, on platforms." The substrate gains "new expressions." Conceptually, "the gamification of the whole Hitchhiker concept becomes real and tested with game designers thinking about how can we make that more gamey and playful." A milestone shift in capability: the jam "helps us set the boundaries around" remixable IP, fork and code-reuse rules between games.

Hedged or possible. Hedged with "potentially" and "perhaps": "potentially several new Hitchhiker games" and "also potentially new expressions of the substrate." The experiment angle is tentative: "perhaps even, yeah, the games can be used as experiments for some of our more serious stuff... around the economics and things like that." The Marvin-as-content path carries explicit risk: "There might be some IP issues there," so the team must be "a little bit careful and specific."
