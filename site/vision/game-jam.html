Scoping the Hitchhiker Game Jam — a global decentralized event, a vibe-coding substrate, Marvin-as-NPC, and remixable IP.

A scoping conversation that runs the Hitchhiker Game Jam initiative through the team's standard discovery questions (what is it / who cares / who's involved / what changes / what's the proof / what makes it real). The proposal is a global, decentralized game-jam event, ideally co-run with the existing Global Game Jam partner (200-300 countries, ~30,000 people, ~3,000 games), issuing a challenge to create Hitchhiker-themed games and giving participants a substrate for vibe-coding them. The intended audience is the global indie-gamer community, classic Hitchhiker game lovers, game studios, and tool/3D-modeling vendors, with an additional angle of LARPing and the physical-digital crossover crowd. A recurring strategic thread is dropping the team's built AI knowledge bases — Marvin and other Hitchhiker characters — into other people's games as NPCs and as tutorial/onboarding guides, while staying careful about the IP line between Marvin-as-guide (their call) and a full Hitchhiker entertainment title. The session closes on making the IP remixable: forking and code-reuse rules between games, and chasing the original H2G2 game developers for an interview and official endorsement to connect the old school lore to what's happening now.

Key points

  • What it is: a global decentralized Hitchhiker Game Jam, ideally partnered with Global Game Jam (~200-300 countries, ~30,000 people, ~3,000 games), built around a challenge to create Hitchhiker games on a provided vibe-coding substrate.
  • Who cares: vibe coders, classic game lovers, the global indie-gamer community (board games, ARGs), fans of the original Hitchhiker game, game studios wanting to collaborate, and the LARP / physical-digital crossover crowd.
  • Tool & studio partners: companies offering game-dev tools and 3D-modeling vendors who want their tools in users' hands; another three gaming companies floated as an interesting angle.
  • Marvin-as-NPC angle: insert the built AI knowledge bases (Marvin, other Hitchhiker characters) into other people's games as NPCs and as tutorial/help/onboarding guides, previews, tasters, and embassies.
  • IP line: Marvin as a guide to another game is our call out / fine; a full game with Hitchhiker Marvin as content falls under entertainment and needs care — Hitchhiker's-Guide-to-other-games framing avoids the problem.
  • What changes: penetration into a new ecosystem, one or several new Hitchhiker games on platforms, new expressions of the substrate, and the gamification of the concept tested by real game designers.
  • Games as experiments: the games could double as testbeds for the more serious economics / mechanics work.
  • Proof & realness: standard metrics (people, games, coders signed up for vibe-coding, indie-game downloads); realness comes from actually playing the games, interviewing the original H2G2 developers, and landing an official partnership.
  • Remixable IP milestone: the jam sets the boundaries for using the characters/terms and the rules for forking/reusing code between games.

Action items

  • Pursue an official partnership with Global Game Jam to co-host the event.
  • Build and ship a vibe-coding substrate for participants to create Hitchhiker games on.
  • Issue the Hitchhiker Game theme/challenge and stand up prizes/awards.
  • Make jam games playable during the festival and across the wider project.
  • Define the Marvin-as-guide vs. Marvin-as-entertainment IP boundary, and the safe Hitchhiker's Guide to [other game] packaging (tutorials, onboarding, tasters, previews, embassies).
  • Reach out to the original H2G2 game developers (per Max's suggestion) for an interview/endorsement and a possible remake — connect the old-school lore to now.
  • Explore tie-ins with the Hitchhiker writers / writing competition and a remix/extension of the original Hitchhiker game.
  • Establish the remixable-IP rules: which characters/terms can be used and how forking / code-reuse between games works.
  • Track metrics: number of people, games, coders signed up for vibe-coding, and indie-game downloads.
