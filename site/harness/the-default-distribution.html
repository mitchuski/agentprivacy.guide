📦 The Default Distribution

The system alone: no results, no chronicles, no fleet. node tools/make_default.mjs generates a clean, shareable harness from the origin repository — the loop, the seven seats, the six trusts, the ten ground rules, the engine and its gates, the blank templates, and the field-guide spar as the runnable example. Every gate passes without the origin's history: run node tools/check.mjs and see. The record starts with you.

Deliberately absent, living upstream

The origin's advancing frontier and run records · the chronicles · the origin operator's fleet (The Harness Paths — any reference in the default resolves upstream) · the origin's evidence statement (The Contribution) · the universe layer (one project's corpus) · the workshop front page. The default carries the constitution and the machine, not the operator's biography — adopting it means your numbers, your ledgers, your chronicle from round one.

Why a default exists

The fleet was separated from the system by ruling: what you adopt is the skeleton — your harness path is a config, not a fork. The default is that separation made distributable: The Setup Pathway walks it end to end, Adopting The Harness maps the harness-vs-auditor decision, and The Seat Contract is the interface your config fills.
