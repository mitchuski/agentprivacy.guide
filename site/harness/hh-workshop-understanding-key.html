UNDERSTANDING_KEY.md — the access ladder (an AUDITOR, and it says so)

The harness in this repo guards translation fidelity — an adversarial,
non-enumerable claim space. This file is the other thing: the
understanding-as-key access ladder, which is an enumerable checklist plus a
human door, i.e. an auditor (ADOPTION Step 0 upstream: what you can
count, count; running the Gap on an enumerable list is the universe-builder's
catalogued mistake). Naming that honestly is part of the design.

The rungs, as checkable facts

Per participant, per rung — every item is a yes/no a script or a stranger can
check:

rung checklist
Traveler consent row signed (CONSENT_LEDGER.md) · ≥1 expression admitted to corpus/
Contributor ≥1 (claim, form) pair of theirs carried through a VALIDATED round (verdict.json replayable)
Author a full triptych of theirs VALIDATED (all three forms declared + census passed)
Mentor served as blind assayer on ≥1 round (named in that round's chronicle; never saw the canon that round)
Fellow ≥1 register claim of theirs folded by the keystone (visible in canon/UNDERSTANDING.md history)

The cookie jar (graduated access to the mage)

Access deepens with the rung — host-scoped, brokered, never a raw credential
in anyone's context (C8):

rung jar
Traveler converse with the mage (read + chat)
Contributor submit triptychs to the round runner
Author propose corpus folds to the steward
Mentor hold the assay seat
Fellow sit with the keystone when the register amends

The steward's weekly key is separate from the ladder — every student holds
it exactly once (CURRICULUM.md).

The door

The last check on every rung is human: the facilitator (and on outward acts,
the First Person) confirms the checklist and turns the key. An auditor plus a
door — never a self-certifying gate, which would be the exact trust the
proverb warns about (C30).
