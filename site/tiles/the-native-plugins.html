🧩 The Native Plugins

A FedWiki page is a column of story items, and every item type is a plugin — a small native module that renders, and often edits, its own kind of paragraph. The federation runs on a shelf of these: most come from the federated-wiki commons, a few are forged here. This page is the shelf, grounded in what the farm actually uses.

From the commons

The plugins the hitchhikers work leans on daily, with their keepers in the commons:

  • markdown · reference · assets · roster · search · activity · video — Ward Cunningham. The workhorses: prose, cross-site links, file folders, the family roster, and the video items the transcription lane reads.
  • frame — Eric Dobbs. Seats a live external page inside a wiki page — how the Game of 42 constellation and the engine views ride inside the wiki.
  • graphviz — Eric Dobbs. Diagrams as text.
  • paragraph · pagefold · image · code · html — the core set that ships with the wiki.

These are npm packages (wiki-plugin-*), each forkable like any page. Attribution stays with their authors; this lab only uses them.

Forged in this lab

  • Tile Glyph Plugin — wiki-plugin-tileglyph: colored, animated navigation tiles carrying an emoji or ASCII glyph. Powers the Tile Wall and the Root Tiles registry; 31 tiles live across the federation.
  • federationmap — wiki-plugin-federationmap: the live hub-and-spoke map on the guide's welcome page — sites sized by page count, one click crosses you in.

In use across the farm

Counted from every page of every host, the shelf in the wild: markdown 17,292 · assets 856 · reference 788 · video 32 · tileglyph 31 · roster 28 · date 13 · frame 6 · activity 4 · search 3 · code 3 · federationmap 2. The video items are the workshop-recording lane; the date items arrived on pages forked from neighbours — that plugin is not yet installed here, so they render as raw text. Installing it is an open lab task.

The lab discipline

Prototype here, ship to the farm, project to the static guide. A plugin that only renders (like tileglyph) survives the static snapshot as styled HTML; a plugin that lives (search, activity, the map) degrades to a note — the live behaviour belongs to the wiki, and that is the reason to visit the Plugin Lab.
